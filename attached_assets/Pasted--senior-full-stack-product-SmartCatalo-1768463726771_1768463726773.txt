Сейчас проект работает, но функционально и визуально не соответствует требованиям. Твоя задача — НЕ писать всё с нуля, а аккуратно ПРОАНАЛИЗИРОВАТЬ текущий код и ВНЕСТИ ИЗМЕНЕНИЯ: исправить баги, улучшить UX/UI, добавить недостающие фичи. Весь интерфейс и тексты — ТОЛЬКО на русском языке.

КОНТЕКСТ (что уже есть по скринам)
- Есть форма добавления товара (SKU, цена, название, описание, категория, URL изображения) и блок “Наличие и статус”.
- Есть создание категории, но без подкатегорий.
- Каталог визуально простой, при добавлении в корзину нет понятной реакции.
- Верхнее меню не закреплено.
- При клике на карточку товара открывается “Товар не найден”, хотя товар существует и описание было добавлено.

ОСНОВНЫЕ ЦЕЛИ (что исправить и добавить)
1) Загрузка товаров должна стать “быстрой и удобной”: Smart Import + несколько фото + варианты (размер/цвет).
2) Категории должны поддерживать подкатегории.
3) Каталог должен выглядеть современно: карточки, анимации, sticky header, понятное добавление в корзину.
4) Исправить страницу товара (product detail): не должен показываться “Товар не найден”, должен показывать описание и галерею.
5) Скидки/акции должны реально работать: пересчет цены, перечеркнутая цена, бейджи, вкладка “Акции”, фильтр “Акционные”.

ОГРАНИЧЕНИЯ
- НЕ подключать внешние сервисы (WAHA/Cloud API пока не трогать).
- Фокус на UI/UX каталога и админки, Smart Import, скидки/акции, карточка товара, варианты.
- Сохранить существующую архитектуру, стили и роутинг, но улучшить качество.

ТРЕБОВАНИЯ К РЕАЛИЗАЦИИ (конкретно)

A) ТОВАРЫ: МНОГО ФОТО + ГАЛЕРЕЯ + ЗАГРУЗКА
- У товара должно быть несколько фото: главное + галерея.
- В админке на форме товара:
  - Добавить upload multiple images (через <input type="file" multiple>) и превью.
  - Поддержать перетаскивание (drag & drop) — желательно.
  - Оставить поле URL как опциональный вариант, но основной путь — загрузка файлов.
- Хранилище: локально (папка /public/uploads или /uploads с отдачей через Next static) + таблица product_images.
- На витрине:
  - На карточке товара показывать главное фото.
  - На странице товара — галерея (карусель/превью).

B) SMART IMPORT (CSV/XLSX) + ИМПОРТ ФОТО ZIP
Сделай отдельный экран в админке: “Импорт каталога”.
Функции:
1) Импорт CSV/XLSX:
  - Авто-сопоставление колонок по заголовкам RU/EN:
    SKU/Артикул, Название, Описание, Цена, Категория, Остаток, ВсегдаВНаличии, ВНаличии, СкидкаТип, СкидкаЗначение, Фото/Images.
  - Предпросмотр первых 20 строк.
  - Валидация:
    ЖЁСТКИЕ ошибки (строка не импортируется): нет sku, нет названия, цена не число, нет категории.
    ПРЕДУПРЕЖДЕНИЯ: нет остатка, скидка без типа, фото не найдено.
  - Режимы:
    - Upsert (по умолчанию): sku существует → обновить выбранные поля
    - Create only
    - Replace catalog (архивировать отсутствующие)
  - Выбор какие поля обновлять: цена/остаток/описание/категория/скидка/фото.
2) Импорт фото ZIP:
  - SKU123.jpg → главное фото SKU123
  - /SKU123/1.jpg, /SKU123/2.jpg → галерея
  - Показать “нераспознанные фото” и дать ручное сопоставление.

Важно: если полноценный ZIP-парсинг слишком долгий, MVP-вариант:
- разрешить загрузку нескольких изображений “пакетом” + сопоставление по имени файла (sku) без ZIP.
Но приоритет — ZIP.

C) ВАРИАНТЫ ТОВАРА (размер/цвет) — чтобы расширить аудиторию
Добавь сущность “Варианты”:
- ProductVariant: product_id, option1_name (например “Размер”), option1_value (S/M/L), option2_name (“Цвет”), option2_value (Black/White), sku_variant (опционально), price_override (опционально), stock_qty, in_stock.
В UI:
- В админке на товаре — “Варианты” (таблица + кнопка “Добавить вариант”).
- На витрине на странице товара:
  - Селект “Размер” и “Цвет” (если существуют).
  - При выборе варианта обновлять наличие/цену (если override).
- В корзину добавлять конкретный вариант (item должен сохранять выбранные опции).

D) КАТЕГОРИИ: ПОДКАТЕГОРИИ
- category.parent_id (nullable).
- В админке:
  - При создании/редактировании категории добавить поле “Родительская категория”.
  - В списке категорий отображать дерево (хотя бы отступами).
- На витрине:
  - Фильтр “Категории” должен показывать подкатегории.
  - Возможность фильтровать по родителю (включая подкатегории) — желательно.

E) ВИТРИНА / КАТАЛОГ: УЛУЧШИТЬ ВИЗУАЛ И UX
1) Sticky header:
- Верхняя панель с названием магазина, поиском, фильтрами и иконкой корзины должна быть закреплена (position: sticky; top:0) и аккуратно отделяться (backdrop blur).
2) Ясная реакция “товар добавлен в корзину”:
- Добавить toast (Sonner) “Добавлено в корзину”.
- Добавить микро-анимацию: иконка корзины “прыгает”/увеличивается на 200мс.
- На карточке — краткий визуальный фидбек (например, галочка/подсветка кнопки).
3) Улучшить карточки:

  - если скидка активна → показать новую цену + перечеркнутую старую (line-through).
  - если акция → приоритет над скидкой категории.
4) Категорийные табы как chips + выпадающий фильтр (уже есть) — сделать красиво и согласованно.
5) Страница товара (Product detail) — современная:
- Галерея, название, цена, скидка, наличие, описание, варианты, кнопка “В корзину”.
- Не показывать “Товар не найден” при валидном товаре.

F) ИСПРАВИТЬ БАГ “Товар не найден”
Сейчас при клике на карточку товара открывается “товар не найден”.
Найди причину и исправь:
- Скорее всего проблема в роутинге: на карточке используется один id/slug, а страница ожидает другой.
- Сделай единый источник истины:
  - либо /product/[id]
  - либо /product/[slug]
  - и корректно генерируй ссылки.
- Обязательно: корректно показывать description и фото.
