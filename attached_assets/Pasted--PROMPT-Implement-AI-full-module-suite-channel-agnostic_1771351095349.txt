3) UNIFIED MESSAGING PROVIDER (CORE)
====================================

Create backend service: server/services/messagingProvider.ts

Interface:
sendMessage({
tenantId,
channel,             // WHATSAPP / TELEGRAM / INSTAGRAM / WIDGET
provider,            // META | WAHA | TELEGRAM | INSTAGRAM | INTERNAL (resolved by channel)
to,                  // phone or ids
text,
meta                 // campaignId, contactId, tags
}) -> { providerMessageId, status }

resolveChannelForContact(tenantId, contactId, preferredPolicy) -> { channel, provider, address, reasonIfBlocked }

Rules:

* If contact.opt_out = true => BLOCK
* Prefer last_channel if connected and allowed
* Else primary_channel
* Else fallback WhatsApp if connected and phone exists
* If WhatsApp selected:

  * If Meta connected, use Meta; else if WAHA connected, use WAHA; else BLOCK
* Return explicit reason when BLOCK/SKIP (no channel connected, missing phone, templates missing, etc.)

IMPORTANT:
If WhatsApp Meta requires templates for proactive messages in your implementation:

* allow two modes:

  1. “text message” only if permitted
  2. “template message” if needed
     For MVP, if template infra not ready, still queue messages but mark NEEDS_ACTION with reason “Нужны шаблоны Meta”.

6) MODULE-SPECIFIC LOGIC
========================

6.1 Reactivation
Audience presets:

* last_inbound > 7/14/30/60/90 days
* exclude negative tags
* require_prior_inbound = true (default)
  Message presets:
* “Напомнить о себе”
* “Новинки / акция”
* “Персональная рекомендация”
  Stop after reply.

6.2 Upsell after order
Triggers:

* after PAID + X days
* after DELIVERED + X days
  Audience: contacts with last order in window
  Message: suggest accessories/related products (use order.items -> related mapping if available)
  Stop after purchase or reply.

6.3 Abandoned dialogs
Trigger:

* conversation inactive for 24/48/72 hours after inbound interest
  Audience: last_inbound exists, no order created, no outbound in last X hours
  Message: “Хотите продолжить? Могу предложить альтернативу/скидку”
  Stop on reply.

6.4 Price/Stock reminders
Triggers:

* product back in stock
* price drop
* promo zone activation
  Audience: contacts who viewed/asked about SKU/category (store interest events if you have; else MVP: manual select tags)
  Message: notify and invite to order.

6.5 NPS/Reviews
Trigger: after COMPLETED + X days
Flow:

* Send “Оцените 1–5”
* If 4–5 -> ask for review + link
* If 1–3 -> apologize + handover to manager (create internal task)
  Store rating.
