# PROMPT: AI-РОП → вкладка “Подключение” (только каналы) + WAHA disclaimer gating + Meta отдельная зона

Stack: React 18 + TypeScript (Vite), Tailwind, Framer Motion. Backend: Express + Postgres. Multi-tenant.

CONTEXT:
AI-РОП уже существует с вкладками: Обзор / Обучение / Тестирование / Подключение / Аналитика / Стратегия.
Нужно реализовать ТОЛЬКО вкладку “Подключение” внутри AI-РОП как единый центр подключения каналов для AI-ответов:

* WhatsApp (2 режима: Meta official и WAHA QR)
* Instagram Direct
* Telegram Bot
  (без CRM, без платежей, без прочих интеграций)

CRITICAL:

* Не делать “ребилд” кабинета. Работать внутри AI-РОП.
* Meta требует отдельного пространства — не пытаться запихнуть всё на одну страницу.
* WAHA: показать обязательное предупреждение + чекбокс “прочитал и согласен” → только после этого становится доступна кнопка подключения.
* Предупреждение должно быть про безопасность/комплаенс (без советов по обходу ограничений).
* Multi-tenant: tenant_id везде.

4) WAHA wizard + DISCLAIMER GATING: /app/ai-rop/connect/whatsapp/waha
=====================================================================

Step 0 (обязательный): Предупреждение
Заголовок: “Важно перед подключением WAHA”
Текст (коротко, по делу):

* WAHA — неофициальное подключение. WhatsApp может ограничить или заблокировать номер при нарушениях правил.
* Запрещено: массовые рассылки без согласия, спам, покупные базы, однотипные сообщения многим контактам.
* Рекомендуется: отвечать на входящие, получать согласие, соблюдать частоту, быстро обрабатывать жалобы/стоп-слова.
* Для максимально безопасной работы используйте официальный Meta канал.

Внизу:
[ ] “Я прочитал(а) и согласен(на). Понимаю риски блокировки номера и что ответственность лежит на владельце номера.”
Кнопка “Продолжить” disabled пока не стоит галочка.

On accept:
POST /api/ai-rop/connect/waha/accept-disclaimer { version: "v1" }

Step 1: QR подключение

* Кнопка “Получить QR”
* Отображение QR + live status:

  * “Ожидаем сканирование…”
  * “Сессия активна”
* Poll status каждые 2s.
* Успех → Step 2.

Step 2: Включить AI на этом канале

* Toggle: “AI отвечает клиентам в WhatsApp (WAHA)” (default ON)
* Optional: “Использовать для заказов из каталога” (если применимо)
* Save.

Step 3: Тест

* “Отправить тест” (внутренний тестовый входящий webhook либо симуляция)
* Показать зелёный “OK” + лёгкая конфетти-анимация.
