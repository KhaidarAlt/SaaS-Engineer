# PROJECT TASK: Full Rebuild of AI Assistant (AI-РОП) Module

You are working on a multi-tenant SaaS project called SmartCatalog.
Stack:

* Frontend: React 18 + TypeScript (Vite)
* Backend: Express (Node.js)
* Database: PostgreSQL
* Multi-tenant architecture (tenant_id required everywhere)
* WhatsApp integration already exists
* Payments (Kaspi Pay) module exists
* Internal CRM exists
* Telegram notifications exist
* amoCRM & Bitrix integrations exist

We need to fully redesign and rebuild the AI Assistant section into a unified AI-Sales Control Center (AI-РОП).

This must be production-ready and scalable.

---

## SECTION 1 — CORE CONCEPT

The AI Assistant page must become a single control panel where the user:

1. Selects AI goal
2. Sees analytics (KPI + funnel + drop-off)
3. Sees readiness status (BLOCKED / WARNING / READY)
4. Runs AI Audit (diagnostics)
5. Trains AI via chat corrections
6. Applies AI recommendations with versioning
7. Manages strategy & behavior
8. Has simplified + advanced modes

The UI must not overwhelm. Default view is simplified.

## SECTION 3 — GOAL READINESS CHECK (CRITICAL)

When user selects goal:

If goal = CLOSE_DEAL:

* Verify at least 1 active payment provider (Kaspi Pay active)
* If not → BLOCKED
* Show UI alert with button “Go to Payments”

If goal = QUALIFY_HANDOVER:

* Verify at least one channel:
  internal CRM OR amo OR Bitrix OR Telegram
* If none → BLOCKED

If goal = CONSULT_MATCH:

* Check catalog completeness
* If missing descriptions/images → WARNING

If goal = ORDER_NO_PAYMENT:

* Check order creation enabled
* If not → BLOCKED

Readiness must show:

* READY (green)
* WARNING (orange)
* BLOCKED (red)

Blockers must NOT count as AI failures in analytics.
