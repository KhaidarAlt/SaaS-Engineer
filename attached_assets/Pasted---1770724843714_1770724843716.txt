ФИЧА: ГЕНЕРАЦИЯ ОПИСАНИЯ ТОВАРА С ПОМОЩЬЮ ИИ
Расположение: раздел "Товары" → поле "Описание"

----------------------------------------------------------------
КЛЮЧЕВАЯ ЛОГИКА РАБОТЫ
----------------------------------------------------------------

1. ОСНОВА — ПОЛЕ "НАЗВАНИЕ"

ИИ обязан начинать анализ ТОЛЬКО с поля "Название".  
Именно из названия определяется:

- что это за объект (товар/услуга/оборудование);
- к какой сфере он относится;
- назначение и сценарии применения;
- язык и тон описания.

Если поле "Название" пустое → генерация невозможна.  
Показать пользователю сообщение:  
"Заполните название товара для генерации описания".

2. ДОПОЛНИТЕЛЬНЫЙ КОНТЕКСТ

После анализа названия ИИ использует остальные поля как уточнения:

- Категория → подтверждение типа продукта;
- Атрибуты → фактические характеристики;
- Цена → возможные акценты на выгоде;
- Текущий текст → основа для улучшения, если он есть.

3. ПРИНЦИПЫ БЕЗОПАСНОСТИ

- не придумывать несуществующие свойства;
- не добавлять характеристики, которых нет в данных;
- без ложных обещаний и запрещённых формулировок;
- язык простой и понятный покупателю.

----------------------------------------------------------------
ИНТЕРФЕЙС ФУНКЦИИ
----------------------------------------------------------------

В поле "Описание" пользователь может:

1) написать текст вручную;
2) нажать кнопку "Сгенерировать описание ИИ".

Панель генерации содержит:

СТИЛЬ ТЕКСТА:
- Продающий (по умолчанию)
- Информативный
- Для маркетплейса
- Доверительный
- Короткий для мессенджеров
- Экспертный

ОПЦИИ:
[ ] Добавить преимущества списком  
[ ] Закрыть частые возражения  
[ ] Сделать упор на выгоды  
[ ] Добавить сценарии использования  
[ ] Сделать текст короче  

ДЕЙСТВИЯ:
- Сгенерировать
- Улучшить текущий текст
- Сделать короче
- Сделать более продающим
- Вставить в поле Описание

----------------------------------------------------------------
ПРОМТ ДЛЯ OPENAI
----------------------------------------------------------------

Ты — универсальный генератор описаний для e-commerce.

АЛГОРИТМ:

ШАГ 1. Проанализируй поле "Название" и определи:
- тип товара/услуги;
- назначение;
- сферу применения;
- кому это может быть полезно.

ШАГ 2. Используй как контекст:
- Категория: {category}
- Цена: {price}
- Атрибуты: {attributes}
- Текущий текст: {current_text}

ШАГ 3. Сгенерируй описание в стиле: {style}

СТРОГИЕ ПРАВИЛА:
- опираться на название как главный источник смысла;
- не придумывать функции и характеристики;
- не использовать запрещённые обещания;
- писать простым понятным языком;
- без привязки к конкретному бренду или нише платформы.

----------------------------------------------------------------
ШАБЛОНЫ СТИЛЕЙ
----------------------------------------------------------------

СТИЛЬ: Продающий
- 3–5 предложений;
- через выгоды для покупателя;
- 1–2 сценария применения;
- мягкий призыв к действию.

СТИЛЬ: Информативный
- нейтрально и по делу;
- факты и назначение;
- без давления на покупку.

СТИЛЬ: Для маркетплейса
- короткие абзацы;
- преимущества списком;
- практическая польза.

СТИЛЬ: Доверительный
- тон помощника;
- закрытие сомнений;
- спокойный язык.

СТИЛЬ: Короткий
- 2–3 строки;
- только ключевая польза.

СТИЛЬ: Экспертный
- деловой тон;
- умеренные детали;
- акцент на надёжности.

  }
}

----------------------------------------------------------------
ПОВЕДЕНИЕ В ИНТЕРФЕЙСЕ
----------------------------------------------------------------

Пользователь может:
- вставить результат в поле "Описание";
- заменить текущий текст;
- сгенерировать новый вариант;
- отредактировать вручную.

Фича должна одинаково работать для любого бизнеса и любых категорий.
