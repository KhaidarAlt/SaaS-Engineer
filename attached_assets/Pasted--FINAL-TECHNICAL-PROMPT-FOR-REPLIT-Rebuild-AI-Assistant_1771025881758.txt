3) ONBOARDING UX (INTERVIEW MODE) — EXACT FLOW
==============================================

AiRopOnboardingPage renders:

<A iRopShell>
  <WowScanIntro />
  <InterviewWizard />
</AiRopShell>

3.1 WowScanIntro.tsx

* Show 2–3s animated “I’m studying your catalog…” screen
* Pull catalog summary from backend: GET /api/ai/catalog/summary
  Response: { productsCount, categoriesCount, avgPrice, promoZoneActive, paymentsReady }
* Animate checklist appearing:
  “Сканирую товары…”
  “Анализирую категории…”
  “Проверяю оплату…”
  “Проверяю промо-зону…”
* End with a “Ready card”:
  “Я изучил ваш каталог: … Я готов продавать. Нужно уточнить пару моментов.”
  Button: “Начать интервью” → starts wizard

3.2 InterviewWizard.tsx

* 6 steps max, progress bar top: <WizardProgress />
* One question at a time in chat-like card
* Each step uses <InterviewStep />

STEPS:
Step 1: Goal selection (SingleSelectCards)

* CLOSE_DEAL / QUALIFY_HANDOVER / CONSULT_MATCH / ORDER_NO_PAYMENT
* If “help me choose” → open InlineAdvisorDrawer with short AI explanation

Step 2: Readiness Check (auto)

* Call GET /api/ai/readiness?goal=...
* Show result: READY/WARNING/BLOCKED with human text
* If BLOCKED show deep-link buttons:
  “Перейти в Платежи” (/app/payments)
  “Перейти в CRM/Интеграции” (/app/integrations)
* Allow “Change goal” quick action

Step 3: Style & Tone (SingleSelectCards)

* short / friendly / premium expert / custom text
* “Посоветуй” opens InlineAdvisorDrawer with rationale

Step 4: Objection strategy (MultiSelectChips)

* “дорого, подумаю, хочу дешевле, сравниваю, есть скидка?”
* plus “Добавить своё”
* If user stuck → advisor suggests best answers

Step 5: Handover rules (MultiSelectChips + numeric threshold)

* “просит человека”
* “сумма > X”
* “нестандартный вопрос”
* “негатив”
* “никогда” (exclusive)
* input for X
* add custom rule

Step 6: Mini Simulation (TestChatPanel embedded)

* show 1 prefilled client message from real catalog:
  e.g. “Сколько стоит <top product>?”
* AI answers; user can:
  👍 approve
  ✏️ edit
  🧠 train
* If edit -> TrainActionModal:
  (1) fix only here
  (2) train future
  (3) add to knowledge
  (4) mark anti-pattern

Finish:

* Show WizardSummary with all chosen decisions
* Button: “Запустить AI-РОПа”
* POST /api/ai/onboarding/complete
* Navigate to /app/ai-rop
