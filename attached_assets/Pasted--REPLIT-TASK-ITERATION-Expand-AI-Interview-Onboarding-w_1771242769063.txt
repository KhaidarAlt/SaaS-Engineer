# REPLIT TASK (ITERATION): Expand AI-РОП Interview Onboarding with Brand/USP/Installments + Product Priorities (tags) + Auto-segmentation

Context:
SmartCatalog is a multi-tenant SaaS (tenant_id everywhere). React 18 + TS (Vite) frontend, Express backend, Postgres.
AI-РОП onboarding already exists (6 steps). We must extend the INTERVIEW to include additional blocks and the “product priority tags” system that scales from 10 SKU to 100+ items.

GOAL:
Onboarding must feel like an interview with a strong Sales Director (РОП).
User answers naturally; if stuck, AI suggests best-practice options.
All answers must persist and later affect AI behavior + recommendations + analytics.

C) PRODUCT PRIORITY MECHANIC (TAGS) THAT SCALES
===============================================

We need a hybrid approach:

1. Auto-segmentation (works for 100+ SKU)
2. Rules-based promotion (category/price-based)
3. Manual pinning (up to 10 SKU) for “sell more” / “flagship”

Add a new Interview Step:

STEP X5 — Promotion Strategy (auto segments + manual pin)
Before asking, call:
GET /api/ai/catalog/segments
Return:
{
newCount, premiumCount, entryCount, slowCount,
topCategories: [{id,name,count}],
avgPrice
}

AI message:
“Я нашёл в каталоге:
• Новинки: {newCount}
• Премиум (выше среднего): {premiumCount}
• Бюджетные (ниже среднего): {entryCount}
• Давно не покупали/не заказывали: {slowCount}
Что будем продвигать активнее?”

Options (multi-select):

* Новинки
* Премиум
* Бюджетные
* Давно не покупали
* Конкретные категории
* Вручную выбрать до 10 товаров
* Ничего не продвигать специально

If “Конкретные категории”:
Show category multi-select (from catalog). Save promoted_category_ids[].

If “Вручную выбрать до 10 товаров”:
Show searchable picker (by name/SKU) with limit 10.
Two manual tag types:

* “Продавать чаще” (PRIORITY)
* “Флагман” (FLAGSHIP)
  Save selected product_ids with priority_type.

Explain limit text:
“Рекомендую выбрать до 10 — так стратегия не размоется.”

========================================================
E) DATABASE / DATA MODEL CHANGES
================================

Add table (tenant-scoped):
ai_business_profile

* tenant_id (unique)
* is_official_representative (bool)
* represented_brands (text[])
* has_own_brand (bool)
* own_brands (text[])
* usp_points (text[])
* usp_free_text (text)
* installment_enabled (bool)
* installment_banks (text[])
* updated_at

Add product tagging (tenant-scoped):
product_ai_tags

* id
* tenant_id
* product_id
* tag_type enum: PRIORITY, FLAGSHIP, NEW, PREMIUM, ENTRY, SLOW
* source enum: AUTO, RULE, MANUAL
* weight int default 0 (PRIORITY/FLAGSHIP can use weight)
* created_at

Auto segments:

* NEW: product.created_at within 30 days
* PREMIUM: price > avgPrice * 1.3
* ENTRY: price < avgPrice * 0.7
* SLOW: no orders in last N days (start with N=60; if no order data, skip)
  Store auto tags either:
  A) computed on the fly (preferred MVP) OR
  B) persisted daily job (phase 2)

Promotion rules (tenant-scoped):
ai_promotion_rules

* tenant_id
* promote_new (bool)
* promote_premium (bool)
* promote_entry (bool)
* promote_slow (bool)
* promoted_category_ids (uuid[])
* updated_at

========================================================
G) AI BEHAVIOR: HOW THESE ANSWERS AFFECT SALES
==============================================

When generating responses:

* If is_official_representative = true → emphasize “официальный представитель”, “оригинал”, “гарантия”, “сервис”.
* If has_own_brand = true → emphasize “собственный бренд”, “контроль качества”, “лучшее соотношение”.
* Use USP points as default persuasion arguments.
* If installment_enabled = true → proactively offer installment option when:

  * customer says “дорого”
  * premium product suggested
  * closing phase before payment
    Mention only the banks user selected.

Product selection/ranking:

* Apply promotion strategy:

  * prefer manual PRIORITY/FLAGSHIP products when relevant
  * prefer segment rules selected (NEW/PREMIUM/ENTRY/SLOW)
  * prefer promoted categories
* Keep variety: don’t push the same SKU repeatedly in one dialog.
